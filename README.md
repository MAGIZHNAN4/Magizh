# Lab Vault v2

## New in v2
- Up to 20 questions per experiment
- Each question has:
  - Question / problem statement
  - Program / code
  - Output image
- Edit, reopen and export all questions together

## Existing features
- Add, edit, delete and search experiments
- Filter by subject
- Browser localStorage
- Preview formatted lab record
- Print / Save as PDF
- Word-compatible export
- Mobile responsive

## Note
Data is still stored locally in the browser. Supabase cloud storage can be added next.
